# AstrBot 校园网故障诊断插件

**版本**: `v1.0.0`
**作者**: `yzdr`

齐鲁工业大学校园网故障智能诊断 AstrBot 插件，支持通过 AI 自动识别并诊断网络问题。

## 功能

- **智能故障诊断**: AI 分析用户描述和截图，自动识别问题类型
- **OCR 图片识别**: 识别截图中的学号、错误信息
- **在线设备查询**: 查询用户账号当前的在线设备列表
- **登录日志查询**: 查看用户近期的登录记录
- **失败登录日志**: 查看登录失败记录及原因
- **多问题类型支持**: 连接故障、服务器问题、DNS问题、IP冲突、Wi-Fi问题、网速慢、账号问题等

## 支持的问题类型

| 类型 | 说明 |
|------|------|
| 连接故障 | 网线松动、网卡问题、IP配置错误、认证超时 |
| 服务器问题 | 目标网站宕机、维护、过载 |
| DNS问题 | DNS解析失败、缓存损坏 |
| IP地址问题 | IP冲突、DHCP冲突、MAC绑定失效 |
| 间歇性断网 | 线路接触不良、信号干扰 |
| Wi-Fi问题 | 信号弱、认证问题、连接私接路由器 |
| 网络中断 | 大面积中断、线路损坏 |
| 网速慢 | 带宽不足、高峰期拥塞 |
| 账号问题 | 多设备在线、强制下线 |
| 证书问题 | 浏览器证书警告 |

## 安装

1. 将插件目录放到 `data/plugins/` 目录
2. 在 AstrBot WebUI 的插件管理页面安装并启用
3. 在插件配置中填写 SAM 服务器地址和管理员账号密码

## 配置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| sam_url | SAM 服务器地址 | https://172.17.21.115:8443/sam/services/samapi |
| admin_user | 管理员用户名 | zzpt |
| admin_pass | 管理员密码 | Zzpt@0923 |
| enable_device_query | 启用设备查询 | true |
| enable_login_log_query | 启用登录日志查询 | true |
| enable_fail_log_query | 启用失败日志查询 | true |
| enable_network_diagnosis | 启用网络诊断 | true |
| rate_limit_seconds | 查询间隔限制(秒) | 60 |
| query_days | 查询天数范围 | 3 |

## 使用

- **群聊**: @机器人 会引导您添加好友并私信进行问题诊断
- **私聊**: 直接发送问题描述或截图，AI 会自动分析并给出诊断结果

### 典型使用场景

1. 发送包含学号或错误截图 → AI 识别并诊断
2. 描述问题症状（如"网速很慢"、"无法连接"）→ AI 给出解决方案
3. 追问后续问题 → AI 继续解答
